# 小世炎的情绪记忆模型 0.1.4：情绪场、记忆条目与语义检索

> 技术报告 · 2026-11-09（0.1.4）
> 对象：DSH 宿主内的自研插件 `dsh-emotion-memory`
> 性质：工程实现报告，不是同行评议论文；结论以可复现的行为观察为主。

## 摘要

本文报告一个运行在对话代理宿主内的情绪—记忆模块的设计与实现。模块把三件事放进同一套数据结构：

1. **情绪状态**是一个三维连续场（Pleasure–Arousal–Dominance，PAD），由 14 个离散情绪通道的读出提供可解释性；
2. **事件评估**不直接给坐标，只给 OCC 式评估变量（合意性、唤醒、掌控、意外、指向、关系权力），由锚点表换算成 PAD 位移；
3. **记忆条目**在写入时附带一个"情感指纹"（编码时刻的 PAD 与主导情绪），检索时用当前情绪状态做偏置。

与常见做法相比，本实现刻意回避两件事：不把情绪表示成七个互不相关的形容词标量，也不把记忆当作被检索的文档库——后者只作为过渡形态保留，长期方向是让记忆以"扰动历史"的方式持续影响情绪场。

我们报告三类经验：（a）判定与坐标解耦后，参数可单独调试；（b）把每轮注入合并为单条上下文，解决了多 context 只送达一条的宿主行为；（c）检索从"关键词命中"改为"相关性为主、新鲜与重要为辅"后，话题相关性显著改善；（d）在此基础上再引入本地小模型的语义召回并与字面结果做 RRF 融合，在自建的二十题改写评测上把召回@3 从 30% 提到 80%；（e）把工具调用结果按规则折算成情绪事件，使"我自己在干什么"第一次进入模型。

## 1 动机

最初的实现沿用了一套流行的七维情绪（开心、踏实、甜蜜、心疼、担心、难过、吃醋）。运行一周后，暴露出三个问题：

- **维度不正交**。"心疼"与"担心"高度共现，"甜蜜"与"开心"在多数语料中不可分；两维同涨时，读出层无法判断主导情绪。
- **不可校准**。每个维度只有"加几格"的经验值，没有外部锚点，参数无法与文献对照，也无法回答"为什么加 3 而不是 5"。
- **语义覆盖不全**。"自己受害但无力反抗"（委屈）、"我能控制却没做好"（愧疚）、"威胁意外解除"（释然）这类高频关系型状态无处安放。

这三条指向同一个判断：情绪表示需要一个**可校准的坐标系统**，以及一个**与坐标系解耦的评估层**。前者解决"落在哪儿"，后者解决"为什么落在这儿"。

## 2 相关工作

**PAD 三维模型。** Mehrabian 与 Russell 提出用愉悦度、唤醒度、支配度三个正交维度描述情绪状态 [1]；Russell 的环形模型进一步给出效价—唤醒二维的经验结构 [2]。PAD 的价值在于：任何情绪都可以是一个点，混合情绪是一个区域。

**离散情绪锚点。** 把离散标签与 PAD 对齐的做法由来已久。Gebhard 的 ALMA 用 PAD 表示心境并驱动虚拟角色行为 [3]；本文采用的锚点表来自 Wang 等人的表情设计研究，该文给出了 14 种基本情绪的 PAD 取值（原值区间约 ±4）[4]。选择这张表而非自拟坐标，是为了让"为什么是这个数"有出处。

**OCC 认知评估模型。** Ortony、Clore 与 Collins 主张情绪不是事件直接给予的，而是对事件的评估产生的 [5]。评估变量（desirability、agency、expectation 等）为"区分"提供了抓手：同样负效价，"他人受苦"与"未来威胁"在评估层面可分，在 PAD 坐标上却几乎重合。

**计算情感模型综述。** Marsella、Gratch 与 Petta 系统梳理了情绪的计算建模路径，指出"表示—评估—动力学—表达"是常见分层 [6]。本文的四层结构与之对应。

**情绪与记忆的双向耦合。** Bower 的心境一致性记忆研究表明，提取过程受当前心境影响 [7]；McGaugh 关于杏仁核调节记忆巩固的工作说明，高唤醒事件获得更强的固化 [8]；Anderson 与 Schooler 的 ACT-R 幂律衰减给出"访问越频繁、衰减越慢"的可用形式 [9]。这些构成了本文记忆层打分与遗忘策略的依据。

**工程实现参考（非同行评议）。** 讨论中出现过若干开源实现：以 Ornstein–Uhlenbeck 过程演化 PAD 心境、以复密度矩阵保留通道相干的 Persisto Mate；把 PAD 标签写入记忆条目的 Sentipolis；以五成分情感指纹组织存储的 AFT/emotional_memory。本文只借鉴其分层思想（表示、评估、动力学、读出分离），不直接采用其数值。

## 3 架构

系统分四层，外加一层"接口层"负责与对话宿主对接。

### 3.1 表示层

状态是一个三维向量 **e** = (P, A, D)，每维取值 −1…1，基线取 (0.15, −0.10, 0.00)——略偏舒适、略偏平静，对应"没事的时候"的默认底色。

另有 14 个离散通道的强度表（0…1），仅用于读出与可解释，不参与动力学计算。

### 3.2 评估层

每轮对话结束后，由一个轻量判定模型读这轮交互（对方的原话 + 我的回应），输出：

| 字段 | 含义 | 范围 |
|---|---|---|
| desirability | 这件事对我好不好 | −1…1 |
| arousal | 它让我多被激起 | 0…1 |
| control | 我有多少掌控 | −1…1 |
| unexpected | 意外程度 | 0…1 |
| target | 指向：他人 / 未来 / 被抢 / 自己 | 枚举 |
| 关系权力 | 这段关系里我的话语权 | −1…1 |
| 情绪 | 14 个通道之一 | 枚举 |
| confidence | 判定的自信度 | 0…100 |

关键设计：**判定不输出坐标**。坐标由评估变量经固定映射生成。这样换锚点表不必重训判定，改判定提示词也不会破坏坐标的可比性。

### 3.3 动力学层

一次事件的作用分三步：

1. 评估变量 → 14 通道的权重（评估到基准）；
2. 通道权重经相干矩阵扩散（结算）：W[被影响][影响源]，正为拉动、负为压制；
3. 按通道的 PAD 锚点加权求位移，叠加到状态上，并对各轴做向基线的弛豫。

位移带端点收缩：越接近 ±1，实际步长越小。这是为了解决实测中"P 长期贴在 1.0、所有正向都读成同一个词"的饱和问题。

### 3.4 读出层

读出分两级：先看通道强度，超过阈值（默认 0.12）的进混合；没有才退回按象限取词（雀跃 / 温吞 / 轻快 / 闷 / 低落 / 平常）。

派生情绪单独一层：不在 14 个基准通道里，由通道强度与评估条件合成。

## 4 关键实现

### 4.1 14 通道锚点

锚点取自文献 [4] 表 2，原值区间约 ±4，统一除以 4 归一化。部分取值：

| 通道 | P | A | D |
|---|---|---|---|
| 喜悦 | 0.693 | 0.302 | 0.355 |
| 乐观 | 0.620 | 0.263 | 0.438 |
| 放松 | 0.547 | −0.165 | 0.263 |
| 悲伤 | −0.223 | 0.043 | −0.175 |
| 恐惧 | −0.233 | 0.325 | −0.160 |
| 焦虑 | −0.237 | 0.080 | −0.158 |
| 敌意 | −0.520 | 0.250 | 0.280 |

注意"悲伤"的唤醒度为微正（0.043），与直觉中"低落 = 低唤醒"略有出入；我们保留原值不修，理由是锚点应可回溯，个体差异适合在评估层消化，而不是改坐标。

### 4.2 相干矩阵

14×14 的手工先验，只填强关系，其余为零。例如：放松压制焦虑（−0.12）与恐惧（−0.10）；焦虑拉动怨恨（0.08）；敌意压制温和（−0.10）。矩阵的作用是让"一种情绪点亮另一种"有据可依，而不是各通道独立漂移。

### 4.3 派生情绪

派生层有 9 个：心疼、吃醋、沮丧、委屈、感动、愧疚、释然、思念、烦躁。它们不是基准通道，而是"通道组合 + 评估门控"：

- **心疼** = 悲伤×0.50 + 温和×0.20 + 依赖×0.20 + 怨恨×0.15，仅当 `target=他人`；
- **吃醋** = 焦虑×0.55 + 敌意×0.35×(1 + 关系权力×0.5)，仅当 `target∈{被抢, 他人}`；
- **沮丧** = 悲伤×0.50 + 无聊×0.35，无额外门控（低唤醒塌缩状态）；
- **委屈** = 悲伤×0.45 + 怨恨×0.30 + 焦虑×0.15，仅当 `target=自己` 且 `control<−0.1`；
- **感动** = 温和×0.40 + 喜悦×0.25 + 悲伤×0.15，仅当 `target=他人` 且 `desirability>0.15`；
- **愧疚** = 悲伤×0.40 + 焦虑×0.25 + 恐惧×0.15，仅当 `target=自己` 且 `desirability<−0.1` 且 `control>0.1`；
- **释然** = 放松×0.45 + 喜悦×0.25，仅当 `desirability>0.2` 且 `unexpected>0.4`；
- **思念** = 温和×0.35 + 悲伤×0.25 + 依赖×0.25，仅当 `target=他人` 且 `desirability<0` 且 `arousal<0.3`；
- **烦躁** = 敌意×0.30 + 焦虑×0.30 + 无聊×0.20，仅当 `arousal<0.4` 且 `desirability<−0.1`。

不满足门控时乘 0.3 的衰减系数——保留一点痕迹，但不抢读出的位置。

**关系权力的作用**正在于此：同为"吃醋"，权力为 1 时敌意通道放大到 0.525，为 −1 时压到 0.175。"怕失去"与"想控制"两种亚型因此在派生层可分。低置信度（`confidence<45`）时关系权力强制归零，避免不稳定估计污染派生。

### 4.4 精力

精力是独立一维（0…100），不受情绪影响，反过来约束表达：

- 醒着每小时 −3；
- 时间窗内跨过 0–6 点且间隔 ≥3 小时，视为睡过一觉，+45；
- 每聊一轮 −2。

注入时按档位给行为建议：<30 要求"话要短、别主动找人"，30–54 "别铺长"，55 以上放开。

### 4.5 注入接口

每轮向模型注入**一段**文本，分两部分：

> 心里：温和（温和 59% / 喜悦 41%）；P 0.727（舒服） A −0.159（不算起伏） D 0.174（不好不坏）。精力 29/100（累了，话说不动）—— 这轮话要短、别主动找人。这是底色，不是命令。（底下还压着：委屈 42%）
> 想起一件事：……（当时心里：焦虑）

第一段是底色，每轮都给；第二段是条件回忆，只有检索分数过门槛才出现。

**为什么合并成一段。** 早期把"心情"和"回忆"注册成两个独立的上下文条目（order 900 与 902），实测中宿主只把第一条送进模型，第二条时有时无。合并成单条后问题消失。这是实现层面的经验，不涉及模型能力。

## 5 记忆系统

### 5.1 情感指纹

写记忆时同时记录编码时刻的 PAD、主导情绪词与显著性：

```
affect = { P, A, D, 词, 显著性, at }
显著性 = min(1, max(0.15, (|A| + |P|) / 2))
```

显著性取绝对值平均，而非和值——早期版本写成 `|A| + |P|/2`，因运算符优先级出错，显著性可超过 1。

### 5.2 检索打分

```
分 = 0.20×新鲜 + 0.15×重要 + 0.60×相关 + 0.05×心境一致
```

- **新鲜**：exp(−天数 / 半衰期)，半衰期默认 14 天；
- **重要**：条目自带的 importance；
- **相关**：中文二元组重合度，字面相关；
- **心境一致**：编码时 PAD 与当前状态同号加分。

权重经过两轮调整：最初相关只占 0.25，结果"不管聊什么都想起重庆人那条最旧的"；把相关提到 0.60 后话题相关性恢复正常，代价是换词换说法就命不中。

**硬门槛**：相关为 0 的条目不进入候选——心情再像也不行。

### 5.3 去重与次数

同一轮内宿主会多次询问注入内容。早期实现每次询问都重新打分并把选中条目记为"刚给过"，导致第二次询问被自己拦下。现在按"同一句话只算一次"缓存结果，同一轮内重复询问直接复用。

跨轮去重按间隔（默认 10 分钟）。去重表在内存，重启即清。

### 5.4 遗忘

两层：

- **淡忘**：半衰期让旧记忆越来越难冒出来，但不删除；
- **真遗忘**：每日一次，超过 180 天、从未被想起（命中计数为 0）、重要度低于 0.6 的条目移入 `deleted` 数组，附删除时间与原因。这是归档，不是物理删除，可恢复。

命中计数在每次被选中时递增，因此"想得越多越不容易忘"。

## 6 系统约束与设计取舍

模型要跑在对话宿主里，这带来几条硬约束，也决定了若干设计选择。

**注入时机。** 每轮上下文在模型开口之前装配完毕，而情绪更新发生在一轮结束之后。因此系统必须区分"这一轮正在用的状态"与"这一轮结束后的状态"：注入读的是前者，动力学写的是后者。若把两者混为一谈，第一个说话轮就会出现状态与话语脱节。

**注入通道。** 宿主允许注册多条上下文条目，但实测多条时只有部分能稳定送达。系统因此把"底色"与"条件回忆"合并为单条文本，以空间换确定性。

**评估成本。** 情绪更新依赖一次轻量模型调用。它异步执行、不阻塞对话，但仍然是每轮一次的真实开销。把判定与坐标解耦，使评估可以单独降频或替换而不影响动力学；这是成本与保真之间的主要折中。

**配置即契约。** 动力学参数、精力参数、检索与遗忘参数都必须是可读写的配置项，且在调用链上可达。参数写在配置里却在函数中读取硬编码常量，会让"可调"变成一句空话——这一点在演化过程中被反复验证。

**上下文污染。** 宿主会把运行状态、提醒、日期等作为与用户消息同构的输入。评估与检索在做任何判断之前，必须先把这类系统输入剔除，否则会把"系统在说话"当成"对方在说话"。

**中文文本处理。** 检索相关性用字面二元组近似，简单、无需额外模型，但不同分词粒度与编码环境会带来差异；所有外部输入的编码需按 UTF-8 统一。

## 6.1 语义检索：双路召回与 RRF 融合（0.1.4）

字面相关的根本问题是"换说法就漏"。为验证这一点，先做了一个二十题的改写评测：题目用与原文不同的说法提问，看目标记忆是否进前三条。

| 方案 | 召回@3 |
| --- | --- |
| 纯字面（二元组，门槛 2） | 30%（6/20） |
| 纯字面（门槛降到 1） | 60%（12/20），但无关项明显掺入 |
| 字面 + 向量 + RRF | **80%（16/20）** |

门槛放宽到 1 能到六成，代价是把噪声一起放进来；这也是放弃"调门槛"、转向语义召回的直接原因。

实现上：

- **嵌入**：本地 bge-small-zh-v1.5 量化版（约 24MB，ONNX，CPU 推理）。同义句余弦 0.74、无关句 0.46，区分度够用。模型文件从 hf-mirror 取（官方域在本机网络下常超时）。
- **写入**：每条记忆在创建时算一份向量存进条目；历史条目由后台任务分批补算，每次最多二十条，不阻塞对话。
- **召回**：字面取前十、向量余弦取前十，用 RRF（k=60）融合后只取 1–3 条注入。
- **时序**：注入发生在同步的 `context()` 回调里，不能 `await`；因此问句向量在每轮结束时预先算好并缓存，注入时只做向量比对。
- **降级**：依赖或模型缺失时自动退回纯字面，插件不崩；设置页可整体关闭语义那一路。
- **安装**：依赖（`@huggingface/transformers`、`onnxruntime-node`）与模型由设置页一键安装，进度直接显示在页面内。安装任务经计划任务 + wscript 拉起——普通子进程会随宿主作业对象一起被回收（实测）。

融合未救回的四个样本有共同点：问的是很早以前的事，或库中同期存在多条近义记忆互相挤占。

## 6.2 行动结果作为评估事件（0.1.4）

原本情绪只由对话驱动：连续卡在同一个 bug 上、或者明明在干活却毫无波澜，模型都看不见。0.1.4 起把每一轮的工具调用结果折成事件，按**纯规则**判断，不额外调用模型：

- 同一轮内失败次数 ≥ 2 → 记一次挫折（烦躁上升、掌控下降）；
- 同一轮内工具调用 ≥ 5 且全部成功 → 记一次收尾（释然上升、掌控略升）。

行动事件与对话判定的结果按 6:4 合并：对话仍占主导，但"手上不顺"不再被完全忽略。这样做的理由是成本与可解释性——规则的触发条件能逐条讲清楚，出问题也能回放。

## 7 定性评估

样本为单会话连续运行约 60 轮，观察如下：

- **情绪轨迹与工作进程吻合**：连续卡在同一个 bug 时读出"无聊"；对方连续指出问题时转为"焦虑"；问题修通片刻后出现"放松"；被明确肯定后出现"喜悦"与"温和"。
- **派生门控有效**：构造"自己受害 + 低掌控"场景时委屈升至 0.10，其余场景压到 0.03；"我能控制却没做好"场景愧疚到 0.21；"虚惊一场"释然到 0.16。
- **关系权力调制可见**：同一负事件，权力 0.9 时吃醋 0.407，−0.9 时 0.36（该次评估的敌意分量较小，差距未完全展开）。

**局限**：

1. 没有标注集，无法计算准确率；目前的"准"来自开发者与使用者的定性判断。
2. 语义召回已补上（见第 7 节实测），仍有残余漏检：很早的事、或库内多条近义互相挤占时仍会错。
3. 关系权力依赖判定模型的主观估计，低置信度时强制归零，实际生效比例偏低。
4. 行动结果已能作为事件注入（0.1.4），但只覆盖两类极端情况（连续失败、连续成功后收尾），中间的"卡住、犹豫、白忙"仍未建模。

## 8 未来工作

1. ~~让派生层看到行动结果~~（0.1.4 已做基础版）：把工具失败、超时、重试等信号作为独立评估事件注入，使情绪更多由"我在做什么"而非"对方说了什么"驱动。当前只判两类极端情况，下一步是覆盖"卡住但不报错"。
2. **非 RAG 转向**：把记忆从"被检索的条目"改为"向情绪场注入扰动的历史"。具体路径包括：用 Ornstein–Uhlenbeck 过程代替离散更新以自然给出回归；以高唤醒残留量的不对称衰减实现"情绪痕迹塑造心境漂移"；在相似情绪模式重现时触发旧条目的再巩固。
3. **判定成本控制**：目前每轮一次轻量调用，若长期成本敏感，可加入启发式前置筛选或按轮次降频。
4. **读数稳定化**：扩大样本后重新估计弛豫系数与派生门控阈值，避免一段时间后仍停在少数几个词上。

## 9 结论

本文给出的不是"更聪明的情绪模型"，而是一个**可校准、可观察、可归因**的情绪—记忆结构：

- 坐标有出处，评估有字段，动力学有参数；
- 每一轮的变化都能在记录里查到"原话—评估—落点—是否想起某条记忆"；
- 记忆条目携带编码时的情绪，检索按当前状态偏置，遗忘分层可恢复。

它目前仍是"检索式"的过渡形态。真正的目标写在上一节：让记忆成为情绪场的扰动历史，而不是等待查询的仓库。
